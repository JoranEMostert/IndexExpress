# CLI Behavior Snapshots (Phase 0)

This directory freezes current user-visible CLI output in three formats (`text`, `json`, `markdown`).

Baseline scenario:

- Mode: `skim`
- Query: `best python web framework for startup MVP`

Files:

- `skim.payload.json` - baseline JSON payload structure shown by `--output json`
- `skim.text.txt` - baseline direct text output (`--output text`)
- `skim.markdown.md` - baseline markdown output (`--output markdown`)
